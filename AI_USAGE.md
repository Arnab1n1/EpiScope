# AI Usage Statement

## Tool and Purpose

| Tool | Purpose | Where |
|---|---|---|
| ChatGPT (OpenAI) | Used as a supporting tool to understand assignment requirements, clarify technical concepts, troubleshoot development issues, interpret execution logs, and improve project documentation. | Selected development, testing, and documentation tasks |

## Representative Prompts

1. "Explain the project requirements and provide a step-by-step implementation guide."
2. "Help me understand and troubleshoot this PySpark execution error."
3. "Explain the pipeline execution results and help me interpret the output."
4. "Review the project documentation and suggest corrections based on the actual implementation."

## Human Verification and Responsibility

The project was configured and executed by the team in the local development environment. The team reviewed the execution logs, examined the results, tested the dashboard, and evaluated the project implementation.

The recorded full-scale execution, analytics results, and automated test results are based on the team's local runs. Each team member is responsible for understanding their assigned modules and being able to explain the implementation and technical decisions during authorship verification.

AI assistance was used for guidance and support. The team remains responsible for the submitted code, results, and documentation.
